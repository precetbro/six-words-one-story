One complete story in exactly six words. The program writes it to `/output/entry.txt`.

## The story

> Grandfather's watch stopped when he did.

Six words: a whole life, a death, and an heirloom that stops
at the same moment its owner does. Everything the watch witnessed
is left for the reader to fill in.

## Run it

```sh
node main.ts
```
